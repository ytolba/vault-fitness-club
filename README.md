# Vault Fitness Club website

A responsive, static marketing site for Vault Fitness Club. It is intentionally dependency-free and ready for GitHub Pages.

## Local preview

Open `index.html` directly or serve the folder with any static file server.

## Content notes

- Primary actions are phone and directions until a verified membership URL is supplied.
- The exterior image and circular mark were derived from user-supplied Vault Fitness Club references.
- Product truth lives in `PRODUCT.md`; durable visual decisions live in `DESIGN.md` after review.
